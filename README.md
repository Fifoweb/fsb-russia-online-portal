# ФСБ — Россия Онлайн: игровой портал

Основной сайт: https://fifoweb.github.io/

Основной репозиторий: https://github.com/Fifoweb/fifoweb.github.io . Этот
репозиторий и адрес `https://fifoweb.github.io/fsb-russia-online-portal/`
сохранены как резервные. Дальнейшие обновления основного сайта публикуются
через `Fifoweb/fifoweb.github.io`.

Неофициальный портал игровой фракции GTA 5 RP проекта «Россия Онлайн». Не является ресурсом ФСБ России или других государственных органов и не действует от их имени.

Вход по Static ID и паролю. Игровой ник остаётся в профиле. Доступны документы и справочник, личный кабинет, привязка Discord, заявки на восстановление и переводы в ФСБ по таблице владельца. В формах используются только игровые данные.

В этом репозитории размещены общедоступные файлы интерфейса и их проверки. Авторизация, база заявок и отправка уведомлений работают через ранее настроенный Supabase; серверные секреты и исходники серверных функций сюда не включены. Публичный publishable key в браузерной конфигурации не является административным ключом.

GitHub Actions публикует только папку `dist/`. Изменения main проходят статическую проверку, поиск секретов и тесты защиты сессий и OAuth redirect. Для Pages выбран источник GitHub Actions.

Локальная проверка: `npm run check` и `npm test`; Node.js 20 или новее. Сайт открывается через HTTP, не через file://. Ссылки и OAuth поддерживают подпапку проекта на GitHub Pages.
